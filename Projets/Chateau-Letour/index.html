Site web - Château Letour

Projet personnel réalisé pour mettre en pratique mes compétences en développement frontend avec HTML, CSS et JavaScript. L'objectif était de créer un site vitrine élégant pour un domaine viticole fictif, avec une interface interactive permettant aux visiteurs de découvrir les vins du château et de recevoir des recommandations d'accords mets-vins personnalisés.

Frontend
HTML CSS JavaScript
Voir sur GitHub

Fonctionnalités principales

  • Navigation responsive avec menu fixe
  • Affichage dynamique de l'image du plat et de la description de l'accord
  • Galerie visuelle des trois cuvées du domaine
  • Formulaire de contact complet (nom, email, téléphone, message)
  • Intégration Google Maps avec localisation du château

Compétences mobilisées

  • Maîtrise de HTML et de stylisation CSS
  • Manipulation du DOM pour le changement dynamique de contenu
  • Logique conditionnelle pour les recommandations de vins
  • Interface utilisateur intuitive et accessible
  • Création d'une identité visuelle cohérente et élégante
  • Conception et développement complet en autonomie

Améliorations à venir

  • Développement de l'application côté serveur pour le traitement du formulaire
  • Base de données pour gérer un catalogue de vins plus large
  • ...
